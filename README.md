# Employee Management System

A console-based Employee Management System developed using Java, JDBC, and MySQL.

## Features
- Add Employee
- View Employee Details
- Update Employee Information
- Delete Employee Records
- Database Connectivity using JDBC
- CRUD Operations

## Technologies Used
- Java
- JDBC
- MySQL
- IntelliJ IDEA

## Concepts Implemented
- Object-Oriented Programming (OOP)
- JDBC API
- SQL Queries
- Prepared Statements
- Exception Handling

## Project Outcome
This project demonstrates how Java applications interact with MySQL databases using JDBC and perform complete CRUD operations efficiently.
